# Easy Request

Easy Request 是一款适用于 IntelliJ IDEA **2019–2026** 的 HTTP 接口调试插件，支持 Java + Spring MVC / Spring Boot，让你在 IDEA 中直接查找、调试和管理接口。

兼容范围从 IDEA 2019.1 起，当前已验证至 2026.2。

## 功能

- **自动识别接口**：按项目和 Controller 展示接口，支持搜索、定位源码，以及从 Controller 方法旁的图标直接打开请求。
- **自动生成入参**：识别路径变量、查询参数、Headers、JSON 和文件上传参数，生成请求示例并展示参数说明。
- **HTTP 请求调试**：支持手动创建请求，配置 Params、Path、Headers 和多种 Body 类型，包括 JSON、文本、XML、表单及文件上传。
- **响应查看**：展示状态码、耗时、响应大小和 Headers，支持 JSON 高亮、格式化、折叠，以及复制和保存响应。
- **多环境切换**：自动读取本地应用端口和 context-path，也可配置测试等环境的地址前缀、Spring profile 和公共 Headers。
- **保存与收藏**：自动保存扫描到的接口，支持修改请求配置、收藏接口及通过文件夹整理收藏；刷新接口列表时保留已保存的配置。
- **多标签调试**：支持临时预览、固定标签、并发请求和批量关闭，重启 IDEA 后恢复标签与草稿。

## 安装

### 方式一：下载最新版

前往本仓库的 **Releases** 页面，下载最新版本的插件 ZIP 安装包，无需解压。

### 方式二：自行构建

1. 下载或克隆本仓库，并安装 **JDK 21**。
2. 在项目根目录执行构建命令（首次构建需要联网下载依赖）：
   - macOS / Linux：`./gradlew buildPlugin`
   - Windows：`gradlew.bat buildPlugin`
3. 构建完成后，在 `build/distributions/` 目录中获取插件 ZIP 安装包，无需解压。

### 安装到 IDEA

1. 打开 IDEA → Settings / Preferences → Plugins。
2. 点击齿轮图标 → **Install Plugin from Disk…**，选择下载或构建得到的 ZIP。
3. 按提示启用插件或重启 IDEA。
4. 点击右侧 **Easy Request** 图标，或通过 View → Tool Windows → Easy Request 打开面板。

## 使用

### 打开接口

打开 Spring 项目后，插件会自动加载接口列表。单击接口可预览，双击可固定标签；也可以点击 Controller 方法左侧的 Easy Request 图标打开请求。

接口列表支持搜索。选中接口后，点击定位源码图标或按 `F4` 可跳转到对应方法。新增或修改源码中的接口后，点击刷新图标更新列表。

### 发送请求

打开接口后，检查自动生成的参数，选择地址前缀并点击“发送”。示例参数可按实际业务需要修改。

也可点击标签栏的 **+** 手动新建请求，选择 HTTP 方法并填写地址。填写完整的 HTTP / HTTPS 地址时，会忽略所选前缀。

| 页签 | 用途 |
| --- | --- |
| Params | 填写查询参数，取消勾选的行不会发送 |
| Path | 填写地址中的路径变量 |
| Headers | 配置当前接口的请求头 |
| Body | 选择无请求体、JSON、TEXT、XML、URLENCODED 或 MULTIPART |

上传文件时，选择 MULTIPART，勾选对应行的“文件”，填写文件绝对路径或点击“为选中行选择文件”。

请求完成后，可在响应区域查看结果、复制内容或保存响应。默认请求超时为 30 秒，可在项目设置中调整。

### 配置环境和公共 Headers

点击请求标题旁的齿轮图标打开“项目设置”：

- 使用“本地（自动）”读取当前接口所属应用的本地地址，或添加测试、生产等环境的固定前缀。
- 按需指定 Spring profile；存在多个候选应用时，选择“配置来源模块”。
- 配置公共 Headers，例如用于鉴权的 Authorization。接口自身的同名 Header 优先；也可在 Headers 页签关闭“自动添加公共 Headers”。

### 保存与收藏

修改请求标题或参数后，点击保存按钮即可保存配置。手动新建的请求首次保存后，会加入接口树的“手动接口”。保存后地址和 HTTP 方法固定，可继续修改前缀、标题及参数。

点击星标收藏或取消收藏接口，在“收藏夹”中可创建文件夹并整理接口。取消收藏不会删除已保存的接口配置。

### 标签和快捷键

单击接口打开临时预览标签，双击标签或编辑请求可将其固定。标签上的 `*` 表示有未保存的修改；右键标签可批量关闭其他标签或左右两侧的标签。

| 快捷键 | 操作 |
| --- | --- |
| `⌘/Ctrl+T` | 新建请求 |
| `⌘/Ctrl+S` | 保存请求 |
| `⌘/Ctrl+Shift+S` | 收藏或取消收藏 |
| `⌘/Ctrl+W` | 关闭当前标签 |
